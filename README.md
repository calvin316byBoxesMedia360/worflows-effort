# worflows-effort

Sandbox de Claude — repositorio de pruebas con **Claude Code en GitHub Actions**.

## Claude en GitHub

Este repo tiene configurado el workflow de Claude Code. Para usarlo:

1. Instala la **Claude GitHub App**: https://github.com/apps/claude
2. Agrega el secret `ANTHROPIC_API_KEY` en
   `Settings → Secrets and variables → Actions`.
3. En cualquier issue o pull request, menciona a `@claude` con tu petición.

Ejemplo en un comentario de issue:

```
@claude crea una función en Python que sume dos números y añade tests
```
