# Carpeta de media

Aquí van las **imágenes y videos editados** de los especiales del día
(ej. `lomo.jpg`, `ceviche.mp4`).

El servidor (`servidor.py`) los sirve en `http://<IP>:5000/media/<archivo>`
y la página de la TV los muestra. El campo `"imagen"` de cada especial en
`especiales.json` debe coincidir con el nombre del archivo que pongas aquí.
